# Frontend ↔ Backend

Интерфейс расположен в `frontend/` и использует [общий контракт API](backend-api.md).
Backend и каталог находятся в том же репозитории: отдельные worktree не нужны.

Из корня проекта:

```sh
npm run setup
npm run dev
```

Vite автоматически проксирует `/api` на порт Backend. Для собранного режима:
`npm run build`, затем `npm start`; Express обслуживает UI и API вместе.
В Docker Frontend работает в отдельном Nginx-контейнере: `/api` проксируется
в сервис `backend`, а `/cart` обслуживается как маршрут SPA.

Если Frontend размещён отдельно, `VITE_API_BASE_URL` может содержать origin
Backend или полный префикс с `/api`. Например, `http://localhost:3001` и
`http://localhost:3001/api` приводят к одинаковым URL запросов. Значение задаётся
при запуске Vite или сборке. Без настройки используется `/api` текущего origin.

## Модули

- `src/lib/api.ts`: создание и восстановление сессии, поиск, корзина,
  преобразование числовых полей API в подписи карточек, проверка локального `cartUrl`.
- `src/components/AssistantWidget.tsx`: история диалога, запрос, результат и явное подтверждение.
- `src/components/ProductCard.tsx`: цена, остаток, технические параметры,
  свойства, сертификаты и кратность заказа из ответа API.
- `src/components/CartPage.tsx`: SKU, количество, цена и сумма из серверной корзины.
- `src/lib/links.ts`: допустимые HTTP/HTTPS-ссылки на источники и сертификаты.

## Поведение

`sessionId` хранится в `sessionStorage` и передаётся в `X-Session-Id`.
Клиент отправляет `{ query, conversation: true }`. Ответ с
`intent: "conversation"` отображается в чате без карточки «Нет подходящих
позиций». История видна во время диалога, вопрос появляется сразу после
отправки. Enter отправляет сообщение, Shift+Enter переносит строку. При
сетевой ошибке доступна кнопка «Повторить»; текст вопроса сохраняется.
Таймаут запросов — `requestTimeoutMs` из `frontend/config.json` (35 секунд).
Таймаут не запускает повторную запись в корзину автоматически.

В приветствии можно выбрать русский или казахский интерфейс; выбор сохраняется
в `localStorage`. Подсказки заполняют поле сообщения для редактирования, а Demo
сразу отправляет пример. Короткие уточнения, включая количество одной цифрой,
допустимы. История сохраняется при смене языка и сворачивании чата. На телефоне
чат открывается кнопкой. Escape сворачивает чат или закрывает подтверждение;
фокус возвращается к вызвавшей его кнопке.

Поиск и выбор товара не меняют корзину. Только явное подтверждение отправляет
`POST /api/cart`; повтор после потери ответа использует тот же `confirmationId`.
Кнопка блокируется на время запроса, а устаревший стартовый GET не перезаписывает
новую корзину. Окно подтверждения можно скрыть во время запроса: это не отменяет
отправку. Кнопка «Проверить добавление» возвращает к состоянию запроса; повтор
сохраняет тот же `confirmationId`, в том числе при повторном выборе товара.
После успешного ответа открывается локальный `cartUrl`, фокус переходит к
заголовку корзины. Обновление страницы загружает ту же серверную корзину.

Файлы не загружаются: Backend принимает текстовые запросы. Корзина
демонстрационная и не связана с оформлением заказов на ekt.kz.

`npm test` из корня запускает Backend и Frontend проверки. Тесты интерфейса
поднимают настоящий API с данными `data/catalog.json`; дополнительно проверяются
потеря ответа, безопасные ссылки, свойства товара, кратность и пользовательский
путь корзины. `npm run build` проверяет TypeScript и собирает Frontend.
